# `pikafish.py`文档

这篇文章提供`pikafish.py`的功能以及实现细节等。

## 功能

皮卡鱼是目前中国象棋第一开源引擎，
因此当前项目的开局库数据训练、自动化测试等，
都需要用到皮卡鱼引擎作为参照对象，
来获得更加优秀的开局库和测试准确度一类的东西。

作为一个基础模块，
`pikafish.py`提供以下功能：

- 验证皮卡鱼环境的存在性
- 从GitHub自动下载皮卡鱼的二进制程序文件压缩包并保存本地
- 自动选择符合当前处理器的最快的引擎版本并删去无法使用的引擎版本
- 运行皮卡鱼
- 设置最大的深度
- 对正在运行的皮卡鱼引擎输入
- （常用接口）实现输入go
- （常用接口）实现输入stop
- 获取正在运行的皮卡鱼引擎输出
- （常用接口）实现获取当前计算深度
- （常用接口）实现到达最大深度之后获取计算结果并输入stop
